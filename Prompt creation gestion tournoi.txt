Possibilité de sélection les compétitions : 




GESTION DES TOURNOIS

Double Mixte :
- 32 équipes
- 8 poules de 4

Double Homme :
- 16 équipes
- 4 poules de 4

Chaque équipe possède :
- Joueur 1
- Club Joueur 1
- Joueur 2
- Club Joueur 2
- Poule
- Rang

Les poules peuvent être figées.
Une fois figées :
- Modification impossible
- Déplacement impossible

MATCHS DE POULES

Chaque poule comporte 6 matchs :

1 vs 2
3 vs 4
1 vs 3
2 vs 4
1 vs 4
2 vs 3

CLASSEMENT DES POULES

Pour chaque match :

Victoire :
+3 points

Défaite :
+1 point

Critères de classement :

1. Nombre de points
2. Différence de sets
3. Différence de points
4. Rang initial

Formule :

Score classement =
Points × 1000
+ Différence Sets × 100
+ Différence Points

VERROUILLAGE DES TABLEAUX

Aucun match de tableau final ne peut être joué tant que tous les matchs de poules ne sont pas terminés.

SCORES

Saisie sur 3 sets maximum.

Match terminé uniquement lorsque :
- Une équipe gagne 2 sets

Après validation :
- Calcul automatique du vainqueur
- Mise à jour classement
- Mise à jour tableau final

Modifier un score terminé :
- Demander confirmation

PLANNING

Paramètres :
- Heure début
- Durée rotation
- Nombre terrains
- Temps minimum de repos

Le planning doit :

- Calculer les rotations
- Répartir DM et DH automatiquement
- Éviter qu’une équipe joue deux matchs simultanément
- Respecter le temps minimum entre deux matchs
- Afficher les équipes en attente

TERRAINS

Un match peut être affecté à un terrain.

Un terrain occupé :
- Ne peut pas être réaffecté

Un match terminé :
- Libère automatiquement le terrain

EMARGEMENT

Chaque participant possède :

- Présent
- Absent
- Cotisation payée

Par défaut :
Présent = false
Absent = true

Si présent :
- Absent = false
- Payé = true

Si absent :
- Présent = false
- Payé = false

Une équipe absente :
- Impossible à programmer
- Impossible de saisir un score
