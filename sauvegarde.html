Génère un fichier SQL contenant les instructions nécessaires pour réinjecter les données sélectionnées (une commande "insert" par ligne). Ce fichier s'exécute ensuite depuis Supabase → SQL Editor, en cas de besoin de restauration.

Les tables sont toujours exportées dans un ordre qui respecte leurs dépendances (ex. les profils avant les utilisateurs), quel que soit l'ordre de sélection. Le fichier neutralise temporairement les contraintes pendant la réinjection, pour éviter tout problème d'ordre.
